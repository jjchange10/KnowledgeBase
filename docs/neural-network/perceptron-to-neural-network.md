# パーセプトロンからニューラルネットワークへ

パーセプトロンは、重み付きの入力の和がある閾値を超えたら発火する、というシンプルな仕組みで論理回路を表現できました。ただし重み・バイアスは人間が手で決める必要がありました。ニューラルネットワークは、この「重みを人間が決める」という制約から抜け出し、**データから自動で重みを学習できるようにするための仕組み**です。この章では、まず学習の話に入る前に、ニューラルネットワークが「与えられた入力から出力を計算する」推論の仕組みを理解します。

## 層で構成されるネットワーク

ニューラルネットワークは、ニューロン（ノード）を並べた「層」を複数つなげた構造をしています。

- **入力層**：データを受け取る層（第0層）
- **中間層（隠れ層）**：入力層と出力層の間にある層（第1層、第2層…）。人の目に直接触れないため「隠れ」層と呼ばれる
- **出力層**：最終的な結果を出す層

たとえば入力2つ・中間層3つ・出力層2つの3層構造なら、重みを持つ層（層と層の間の矢印）は2つなので「2層ネットワーク」と呼びます（層の数え方は書籍によって流儀が違うので注意が必要です）。

## パーセプトロンとの違いは活性化関数だけ

前章のパーセプトロンは、入力 `x1`, `x2` と重み `w1`, `w2`、バイアス `b` から、次の重み付き和を計算していました。

```
a = b + w1*x1 + w2*x2
```

パーセプトロンでは、この `a` を**ステップ関数**（0を境に0か1に切り替わる関数）に通して出力 `y` を決めていました。

```
y = h(a),   h(x) = 0 (x ≤ 0), 1 (x > 0)
```

ニューラルネットワークでの計算は、実はこの式と全く同じ形をしています。違うのは、`h(x)` に使う関数（**活性化関数**）だけです。ニューラルネットワークでは、ステップ関数の代わりに、シグモイド関数のような**滑らかに変化する関数**を使います。

- 重み付き和を計算する部分（`a = b + w1*x1 + w2*x2`）→ パーセプトロンと同じ
- その結果を変換する活性化関数 `h(x)` → ここだけが違う

## 活性化関数の種類

### ステップ関数

パーセプトロンで使われていた関数です。入力が0を境に、出力が0か1に**急激に切り替わります**。

```
h(x) = 0 (x ≤ 0)
       1 (x > 0)
```

### シグモイド関数

ニューラルネットワークでよく使われてきた活性化関数です。

```
h(x) = 1 / (1 + exp(-x))
```

ステップ関数とは違い、出力が0から1の間を**滑らかに連続的に変化**します。この「滑らかさ」が、次章で扱う勾配降下法（微分を使ってパラメータを少しずつ更新していく学習方法）にとって重要になります。ステップ関数は微分するとほとんどの点で0になってしまい、勾配を使った学習ができません。

### ReLU（Rectified Linear Unit）

近年のニューラルネットワークでよく使われる活性化関数です。

```
h(x) = x (x > 0)
       0 (x ≤ 0)
```

0以下は0、0より大きい部分はそのまま入力を返す、というシンプルな関数です。

### なぜ活性化関数は非線形関数でなければならないか

活性化関数に**線形関数（`h(x) = c*x` のような比例の関数）を使ってはいけません**。理由は、線形関数を何層重ねても、結局1つの線形関数と同じ計算しかできなくなってしまうからです。たとえば `h(x) = c*x` を3層重ねると `y(x) = c*c*c*x` となり、これは `a = c^3` とおけば `y(x) = a*x` という1層の線形関数と全く同じです。層を重ねる意味を出すためには、シグモイドやReLUのような非線形関数を使う必要があります。

### 何が起きたか

- 「① 3つの活性化関数を比較」では、`x` を0付近でスライドさせると、ステップ関数だけが0と1の間を**瞬間的にジャンプ**するのに対し、シグモイドはなめらかな曲線を描くのが分かります。ReLUは0以下では完全に平ら（出力0）で、0より大きい範囲では傾き1の直線になります。
- 「② パーセプトロンとの違いを見る」では、AND/OR/NANDそれぞれのプリセットで `a` の値は完全に同じまま、出力だけが「0か1」（パーセプトロン）と「0〜1の連続値」（ニューラルネットワーク）に分かれることが確認できます。重み付き和を計算する部分は変えずに、活性化関数だけを差し替えている、という3章の要点がそのまま数値で再現されています。

## まとめ

- ニューラルネットワークは、入力層・中間層（隠れ層）・出力層という層構造を持つ
- パーセプトロンとニューラルネットワークの計算の骨組み（重み付き和 `a = b + w1*x1 + w2*x2`）は同じで、違いは活性化関数だけ
- パーセプトロンはステップ関数（急激に切り替わる）、ニューラルネットワークはシグモイドやReLUのような滑らかな非線形関数を使う
- 活性化関数を線形関数にすると層を重ねる意味がなくなるため、非線形関数を使う必要がある
