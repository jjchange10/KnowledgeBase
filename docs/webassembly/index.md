# WebAssembly

WebAssembly（Wasm）は、ブラウザ上でネイティブに近い速度でコードを実行するためのバイナリ命令フォーマットです。RustやC/C++で書いたコードをコンパイルしてブラウザで動かす、といった用途で使われています。Rustとの組み合わせを中心に、実際に手を動かしながら理解したことをまとめています。
